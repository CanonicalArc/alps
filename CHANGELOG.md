## [0.9.0] - 2026-10-12

Initial public release from CanonicalArc, starting a new repository history.

### Included

- Three self-contained Skills: `design-process-description`, `design-agent-work-system`, and `create-process-models`, with their principles and supporting resources.
- A process model profile that packages one model as one Agent Plugin: explicit membership, complete process Markdown, `metadata.title`, string-valued I/O metadata, and shared artifact definitions.
- Governing criteria, policies, and requirements retained as Controls in source descriptions, with I/O relationships distinct from execution order, readiness, and success.
- Agent Plugins packaging and Claude, Cursor, and Codex adapters, with installation and repository links pointing to CanonicalArc.
- English source documents and reviewed Japanese translations, including usage examples and model-creation guidance.
- A service-assessment example with exact numerical boundary comparisons and separate evidence for description review, tool behavior, and work-system evaluation.
- Validation for Skill and Plugin formats, distribution paths, translation source hashes, release references, relative links, and the example tool.

See the [release notes](docs/releases/0.9.0.md) ([Japanese](docs/locales/ja/releases/0.9.0.md)) for the release contents and installation guidance.
